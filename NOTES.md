# Что я узнал, делая этот проект

## Технически
- Как организовать CLI на `argparse` с подкомандами
- Как писать тесты через pytest с фикстурами `tmp_path`
- Как работает `Enum` для фиксированных значений
- Как делать многоуровневую сортировку через кортеж-ключ
- Как подружить `dataclass` с JSON-сериализацией

## Процесс
- Git workflow: `pull --rebase` перед каждым push
- GitHub Actions: запуск тестов на 3 версиях Python
- Как упаковать проект через `pyproject.toml`
- Как выпустить релиз с тегом `v1.0.0`

## Что было сложно
- Обратная совместимость JSON — старые задачи без `due` не должны падать
- Настройка `conftest.py`, чтобы pytest находил пакет
- Красивый вывод через `rich` без потери читаемости тестов
